# T-61: Release or publishing compromise

- Area: Development, supply chain and operations (G-14)
- Adversary: A-6, A-2
- Status: **Partial.** npm only; unexercised. Residual: a branch can publish unless the `npm` env is main-only (owner); GitHub, Sigstore, npm trusted; no ballot client yet.

## Threat

A malicious npm release or ballot-client release is signed and published.

## Mitigation

Double build with hash comparison, Sigstore/cosign keyless signing, SLSA provenance, OIDC trusted publishing with no tokens, `next` tag only (P0-3).

Index: [[THREAT_MODEL]].

- 2026-10-11 (P2-11 part 1): the API image is reproducible: a bundle `repro-build` already compares, on a Node base pinned by digest, with layer times clamped to the commit (`SOURCE_DATE_EPOCH`, `rewrite-timestamp`). Building it twice, signing and deploying by digest is part 2 ([[railway]]).
