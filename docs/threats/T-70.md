# T-70: Pattern ("Italian") attack on individually decrypted ballots

- Area: Coercion and vote buying (G-11)
- Adversary: A-4
- Status: **Needs decision** (P1-4). Residual if adopted: ranked-choice elections with many candidates remain exposed, and the result must say so.

## Threat

Where a tally decrypts every ballot (a mixnet), a coercer or buyer assigns each voter a rare pattern, such as a unique full ranking, and checks the published plaintexts for it.

## Mitigation

Plurality and approval use a homomorphic tally that never decrypts an individual ballot; only ranked choice would use a mixnet (P1-4 ADR, [[0003-tally-scheme]]). Pattern limits for ranked choice belong to the follow-up mixnet ADR before P5-1.
