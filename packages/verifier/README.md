# @abolishus/verifier

The independent verifier for [Abolish](https://github.com/abolishus/abolish) elections: downloads the public bulletin board and recomputes and checks the whole election without trusting our servers.

**Status: placeholder.** `0.0.0` holds the package name; the first real API lands with STATUS item P1-19. Prereleases are published as `next`, signed and with provenance (see the repository README, "Releases").
