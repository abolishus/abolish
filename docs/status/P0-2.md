# P0-2: Storybook under Vite+

- State: in review
- Phase: Phase 0: Bootstrap

## Scope

Storybook under Vite+ smoke test: confirm on day one that Storybook works under Vite+. Use a minimal `packages/ui` with one component, a story, an interaction test and an axe check, wired to `test:storybook`. If it doesn't work, record exactly why under Blocked, along with the workaround.

## Notes

Storybook works under Vite+. `packages/ui` holds one component (`Button`, a native `<button>`) and three stories with play functions (click, keyboard activation, disabled). `test:storybook` runs every story through `@storybook/addon-vitest` as a Vitest browser-mode test in headless Chromium (`vite-plus/test/browser-playwright`), then axe through `@storybook/addon-a11y` with `a11y.test: "error"`, restricted to the WCAG 2.0–2.2 A and AA rules. `storybook build` and `storybook dev` work too. `test` runs a node-side check that every component has a story.

Checked by mutation, locally: an unlabelled button (axe `button-name`), a low-contrast one (axe `color-contrast`) and a play function with a false assertion each fail `test:storybook`.

Versions: `storybook`, `@storybook/react-vite`, `@storybook/addon-vitest` and `@storybook/addon-a11y` 10.6.1; `vitest` and `@vitest/browser-playwright` 5.0.1 (Vite+'s bundled Vitest; `addon-vitest` has a required `vitest` peer, so the package declares it, as Vite+'s migration rules prescribe); `playwright` 1.63.0; React and React DOM 19.3.0.

What it took: only the owner's `trustPolicyExclude: [semver@6.3.1]` (see the earlier note below). `allowBuilds` stays empty. esbuild (a Storybook dependency) has a postinstall script, so a plain `vp install` or `vp add` reports `ERR_PNPM_IGNORED_BUILDS` after writing the lockfile. The repo's installs (CI's setup action and the session hook) run with `--ignore-scripts` and succeed. The script only verifies the platform binary that the optional `@esbuild/<platform>` package already supplies, so Storybook runs without it. An explicit `esbuild: false` entry would silence the error, but it would also disarm CI's `pnpm-selftest`, which uses esbuild as its probe for unapproved build scripts. Changing that probe is a `ci:` matter and isn't needed.

Known-weak:

- Storybook 10.6.1 declares an optional peer `vite-plus@^0.1.15 || ^0.2.0`, so pnpm warns about Vite+ 1.0.0. It works; the warning goes when Storybook widens the range.
- Locally, a session's preinstalled Chromium may not match Playwright 1.63.0's expected build (1243); point `PLAYWRIGHT_BROWSERS_PATH` at a directory linking the installed build. CI installs the matching browser.
- The axe check only covers what renders in a story; it can't judge reading order or wording. P2-7 brings shadcn/ui, Tailwind and i18n.

Earlier note (blocked, 2026-10-10): Storybook 10.6.1 itself is old enough and resolves, but `@storybook/react-vite` depends on `react-docgen` 8 → `@babel/core` 7 → `semver@^6.3.1`, and `vp add` failed with `High-risk trust downgrade for "semver@6.3.1"` from `trustPolicy: no-downgrade`. Registry metadata shows a false positive: `semver@6.3.1` (and `5.7.2`) are July 2023 security backports published by an npm maintainer without provenance, after `7.5.1`–`7.5.4` had been published with provenance. The owner added the exclusion on 2026-10-11.
