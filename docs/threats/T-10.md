# T-10: Account-to-ballot linkage on the server

- Area: Ballot secrecy, unlinkability and privacy (G-3, G-4, G-5, G-12)
- Adversary: A-2, A-1
- Status: **Planned.** Residual: network metadata, T-11.

## Threat

A table, log line, cache key, queue job or metric joins an account (or a session, cookie or IP) to a ballot or poll participation.

## Mitigation

Accounts and voting identities are separate systems, including the recovery backup (T-20); the ballot path carries no account credential. A test asserts that no table can join them (P2-1, built): every table is classed as board or operational, no foreign key starts or ends at a board table, and no board column has an account-like name. Logs, caches and queues have no such test yet (P2-3, P2-4). Migrations rules (`.claude/skills/migrations`).

## History

- 2026-10-11 (P2-1): the schema no-join test is built. It covers tables only, and the column deny-list matches by name, so a renamed linking column would pass; review of each migration still has to catch that.
