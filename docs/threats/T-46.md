# T-46: Vote buying by secret sale

- Area: Coercion and vote buying (G-11)
- Adversary: A-4
- Status: **Not mitigated.** Remote voting with a transferable secret can't prevent it. Real coercion resistance (for example JCJ/Civitas-style fake credentials) is out of scope until an ADR revisits it.

## Threat

A voter sells their voting-identity secret; the buyer can vote and check.

## Mitigation

None beyond re-voting, which the seller can use to cheat the buyer until close.
