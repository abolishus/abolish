- Branch: `claude/p1-18b`

## Scope

[[tally]] (Tally window) defines `s_S`, the counted extent's last segment, and `t_S`, when its checkpoint is due, from `W_S`, and every term of `W_S` is followed by the **contract-event window** `W_C`: one summed constant of the immutable contracts the definition names, in which a contract event goes from submission to the board. [[P1-18]] was to fix it and closed without doing so ([[P1-18]], Part 4c-2b-2a, Known-weak: "`W_C` itself is still to be fixed by the contracts"), so `s_S` and `t_S` are unknown everywhere, and only their floors are used:

- the trustee node's tally can't read its counted set ([[P2-13]] part 5b-2b), so no seat opens a cell, and with no published tally the everyday results ([[P2-25]], [[P2-24]] part 4, [[P2-9]], [[P2-14]] part 8c) wait;
- the verifier's 4.6 point 2, 5.6, 6.2's `opening-late` and the seal can't be decided ([[P1-19]], [[P4-3]]);
- the release's forced-path windows take `W_C` as 13 hours, which [[tally]]'s own sum (forced inclusion, missed slots, L1 finality, boarding) doesn't fit.

2. **Its readers**, each in the item that owns it: the trustee node's counted set ([[P2-13]] part 5b-2b), the verifier's counted-extent checks ([[P1-19]], [[P4-3]]).
