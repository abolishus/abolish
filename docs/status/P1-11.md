# P1-11: Group and hash layer

- State: in progress
- PR: #23 (ADR [[0007-group-and-hash]]; the group and hash layer follows on this branch)
- Branch: `claude/p1-11`
- Phase: Phase 1: Threat model, spec, crypto core, circuits, verifier, reference election (CLI only)

## Scope

Group and hash layer: point/scalar codecs with subgroup checks, hash-to-field and domain separation, plus published vectors.

## Decision

[[0007-group-and-hash]], accepted by the owner on 2026-10-10 (option A): ristretto255 (RFC 9496), SHA-256 as `H`, RFC 9380 `hash_to_ristretto255` for `h`, and RFC 9497's `HashToScalar` construction for Fiat–Shamir challenges. Threats: T-39, T-31, T-30 (T-30 and T-39 updated).

## Next on this branch

The group and hash layer in `packages/crypto`, as the ADR's Consequences list: `@noble/curves` 2.4.0, strict element and scalar codecs, `H`, `HashToScalar` and `hash_to_ristretto255` with explicit `DST`s, the spec updates to [[notation]] and [[domain-separation]], `h` and codec vectors, and the published RFC 9496, 9380 and 9497 vectors.

## Known-weak

- The 6.4-bit static-DH bound above 2¹⁷ queries rests on a probabilistic factor search (Pollard's rho, 2²³ iterations); the implementation PR publishes the script.
- No published vector covers `hash_to_ristretto255` in one step; ours are built from the two published halves.
