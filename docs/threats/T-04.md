# T-04: Double voting in one poll

- Area: Eligibility and Sybil resistance (G-1, G-2)
- Adversary: A-9
- Status: **Planned.**

## Threat

One identity has two ballots counted in the same poll.

## Mitigation

Each ballot carries a ZK proof of group membership and a per-poll nullifier (Semaphore v4 groups; T-07 covers which proof system); a repeated nullifier is never a second vote: it is a re-vote, and only the one ballot selected by the re-vote rule counts (T-33; P1-13, P1-17).
