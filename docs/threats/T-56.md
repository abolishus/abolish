# T-56: Compromised GitHub Action or CI runner

- Area: Development, supply chain and operations (G-14)
- Adversary: A-6
- Status: **Partial.** Residual: GitHub-hosted runners and GitHub itself are trusted.

## Threat

Compromised GitHub Action or CI runner.

## Mitigation

Actions pinned by full commit SHA with a version comment, checked by CI. The "release at least a week old" rule and minimal workflow permissions are enforced only by review.
