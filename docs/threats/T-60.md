# T-60: Compromised toolchain binary

- Area: Development, supply chain and operations (G-14)
- Adversary: A-6
- Status: **Partial.** Hashes are trust-on-first-use; `repro-build` can't detect a deterministic malicious binary.

## Threat

(nargo, bb, Foundry).

## Mitigation

Pinned versions with sha256 checks (`.github/scripts/install-toolchain.sh`); CI requires nargo, bb, `@noir-lang/noir_js` and `@aztec/bb.js` to name one Noir and one bb, which bbup's `bb-versions.json` maps one to the other (P1-16b).
