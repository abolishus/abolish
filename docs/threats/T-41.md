# T-41: Targeted malicious client

- Area: Client integrity and cast as intended (G-6, G-13)
- Adversary: A-2, A-1, A-7
- Status: **Planned.** Residual: a voter who loads the client from abolish.us without checking its hash trusts whoever serves that domain. Hash-checking in a browser has no good UX; the native app (P5-2) closes this for its users. Under P1-3 (option B), a malicious client can also post an invalid share on the voter's last ballot; the proven complaint can arrive after close, too late to re-vote, so that vote is nullified.

## Threat

Whoever serves the JavaScript serves a modified ballot client to one voter.

## Mitigation

The ballot client is a reproducible, signed, hash-addressed static build pinned to IPFS (P2-8, P0-3); the verifier checks a served client against a signed release (P1-19); `abolishus.eth` and a second domain serve the same hash (P4-4).
