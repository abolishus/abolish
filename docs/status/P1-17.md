## Notes

- Requirement from verifier 2.4 (P0-ops-8): the membership proof must bind the voter's tier inside the circuit (tier-separated leaves, or a root or public input the circuit computes), so two tiers with identical members still have distinct roots and a ballot's proven tier is unambiguous (T-01, T-13). A root wrapped outside the proof doesn't satisfy it. Register any new tag in `docs/spec/domain-separation.md`.
