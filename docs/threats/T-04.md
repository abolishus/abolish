# T-04: Double voting in one poll

- Area: Eligibility and Sybil resistance (G-1, G-2)
- Adversary: A-9
- Status: **Planned.**

## Threat

One identity has two ballots counted in the same poll.

## Mitigation

Each ballot carries a ZK proof of group membership and a nullifier per poll and tier group (Semaphore v4's circuit and Groth16 proofs, [[0009-membership-proof]]; scope and checks in [[membership]]); a repeated nullifier is never a second vote: it is a re-vote, and only the one ballot selected by the re-vote rule counts (T-33; P1-13, P1-17).

## History

- 2026-10-11 (P1-17): the proof system is Semaphore v4's Groth16 circuit, and the scope binds the definition hash and the tier's root ([[0009-membership-proof]], [[membership]]). One identity in two tier groups can have one ballot counted per tier, which G-2 allows.
