# T-34: Election definition substitution

- Area: Integrity and verifiability (G-7, G-8, G-9)
- Adversary: A-2
- Status: **Planned.**

## Threat

Options, rules, electorate, trustee keys or the closing time change after voting opens, or different voters see different definitions.

## Mitigation

The definition's hash is registered on L2 before opening; the ballot client and the verifier check it; ballots bind to it (P1-18, P1-12). Display text, kept outside the definition, is checked against the definition's commitment by the ballot client and any challenge checker before it is shown ([[display-text]], P1-8, P2-8).

Index: [[THREAT_MODEL]].

A ceremony transcript is bound to one definition by the stub hash; `election_id` is assigned by the registry and has exactly one definition, write-once; the transcript hash need not be unique. Residual: translations aren't checked against each other, so the cast-confirmation screen and challenge checkers show every translation's label (T-41).

Still to come: the trustee registry (P1-18, part 3), which the ceremony check depends on, and ballots binding the hash (P1-12, P1-17).
