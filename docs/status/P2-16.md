## Scope

[[0027-trustee-panels-and-live-results]], Parts 1 and 3:

- **Author-added trustees.** A ballot's opening is split additively in two; the default half is shared to the default panel and the author half to the author's panel, each with its own threshold, so a ballot opens only with both thresholds and the author panel can never lower secrecy below the default panel's. The definition binds the author panel's keys, threshold and ceremony transcript; the verifier checks them off chain. If fewer than `k_A` author seats take part at the close, the poll can never be counted, and the UI says so plainly.
- **The transitional panel.** At launch the default panel is ours alone (4-of-7, seats spread so no machine, provider or keyholder holds 4). Every page and receipt says "During launch, Abolish alone holds the key for this poll"; only everyday polls run under it, checked through a panel kind in the release pins and the trustee registry and a poll class in the definition; shares are destroyed after each final count; seats hand over to named independent trustees before the first civic-record poll.
