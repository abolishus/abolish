# T-64: Deployed bytecode differs from reviewed source

- Area: Development, supply chain and operations (G-14)
- Adversary: A-2, A-6
- Status: **Planned.**

## Threat

Deployed bytecode differs from reviewed source.

## Mitigation

Every deployed contract's source is verified on the explorer (P1-18); the verifier checks the bytecode at each address against the release build (P1-19).
