# @abolishus/crypto

The protocol core of [Abolish](https://github.com/abolishus/abolish): canonical encodings, ballot encryption, validity proofs, threshold decryption and the bulletin-board model. Depends only on `@noble/*`.

**Status: placeholder.** `0.0.0` holds the package name; the first real API lands with STATUS item P1-9. Prereleases are published as `next`, signed and with provenance (see the repository README, "Releases").
