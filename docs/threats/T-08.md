# T-08: Electorate definition manipulation

- Area: Eligibility and Sybil resistance (G-1, G-2)
- Adversary: A-2
- Status: **Planned.** Who may define an organisation's electorate is the organisation's problem, not ours; we make the definition public and fixed.

## Threat

A closed electorate (organisational vote) is defined with extra or missing members.

## Mitigation

The electorate (group root at a fixed block) is bound into the election definition, whose hash is on L2 before voting opens (P1-18). Each tier's root is at an L2 block strictly before the one that registers the definition, so the additions behind it are public before anyone votes ([[election-definition]], The electorate is in the past).

## History

- 2026-10-11 (P1-10b): each tier's `root_l2_block` must be strictly before the block that registers the definition, so the additions behind a root are public before voting; a definition naming a later block fails [[verifier]] 2.4 and P1-18's registry rejects it ([[election-definition]], The electorate is in the past). Without it, an insider operating a group's signer could commit to a root whose additions it posts only after close, shutting honest voters out invisibly.
