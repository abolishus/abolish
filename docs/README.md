# Abolish docs

This folder is an Obsidian vault. Link with `[[wikilinks]]`.

- [[PROJECT_BRIEF]]: the owner's brief (verbatim)
- [[STATUS]]: the work-queue index, blocked, known-weak and decisions to review; one file per item in `status/`
- [[THREAT_MODEL]]: threats with IDs, cited by every decision; one file per threat in `threats/`
- `adr/`: architecture decision records ([[0000-template]])
- `spec/`: protocol and canonical-encoding spec for independent verifiers
- `runbooks/`: operational procedures
