# T-55: Malicious or hijacked npm dependency

- Area: Development, supply chain and operations (G-14)
- Adversary: A-6
- Status: **Partial.** In place for the lockfile, and for the gated packages' declared dependencies and imports. Residuals: a malicious release of any dependency older than 7 days, or a long-con maintainer, passes every check. The build toolchain (vite-plus and its rolldown, oxc and tsdown closure) is trusted: every bundle check, `repro-build` and the release double build run the same bundler, so a malicious toolchain release can inject code into every published package and the ballot client while writing honest-looking source maps. Dev dependencies run unconstrained in tests and builds. The import lint is a tripwire for a fixed list of loader names (`require`, `createRequire`, `getBuiltinModule`, `eval`, `Function`, workers, `process.dlopen`, `process.binding`); evaluator gadgets such as a function's `.constructor`, string timers, script elements and WebAssembly are caught only by review. Runtime guards still to add: a ballot-client CSP without `unsafe-eval` (P2-8) and running the verifier CLI with `--disallow-code-generation-from-strings` (P1-19).

## Threat

Malicious or hijacked npm dependency.

## Mitigation

Exact pins in the pnpm catalog; 7-day minimum release age; registry-only resolution with integrity matching the registry; no install scripts outside `allowBuilds`; provenance-downgrade refusal; `packages/crypto` resolves to `@noble/*` only, with an `@noble`-only lockfile closure, `src` imports limited to declared dependencies and a packed bundle that inlines no `node_modules` code, and the verifier only to gated packages and `@noble/*` (CI `gated` check, P1-9); `claude-review` justifies every added package (AGENTS.md, Dependencies).

## History

- 2026-10-11 (P2-5 part 1): `better-auth` and `@better-auth/passkey` 1.7.7 enter `packages/core`, with 45 lockfile packages, among them `@simplewebauthn/server` and the `@peculiar/*` ASN.1 and X.509 parsers. None reaches a gated package's closure (the `gated` check passes) and none has an install script. better-auth's telemetry is off in its options, and `createAccounts` refuses to start if `BETTER_AUTH_TELEMETRY` would switch it back on.
- 2026-10-11 (P0-2): Storybook and its Vitest browser-mode runner join the dev dependencies of `packages/ui` (about 200 packages, none in a gated package's closure). Two settings were needed: `semver@6.3.1` is excluded from the provenance-downgrade check by the owner's decision (a 2023 security backport published without provenance), and esbuild's install script is denied explicitly in `allowBuilds` (its platform binary comes from an optional package, so the script isn't needed). These dev dependencies run unconstrained in tests and Storybook builds, like every other dev dependency.
