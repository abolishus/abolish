# T-44: Benaloh challenges are rare

- Area: Client integrity and cast as intended (G-6, G-13)
- Adversary: A-2, A-3
- Status: **Partial.** Detection depends on enough voters challenging; we can't force them.

## Threat

A cheating client cheats only voters unlikely to challenge.

## Mitigation

The client can't know in advance whether a ballot will be challenged (it commits before the voter chooses cast or challenge) (P1-13).

## History

- 2026-10-12 (P1-13 part 3a, [[0021-challenged-ballots]]): the tracking code is always shown before the choice and scanned passively, but the client can still guess whether it was recorded (time on the screen, focus events, an earlier challenge's handover, its own memory of past challenges) and cheat only the voters it guesses don't check; it is caught only as often as it guesses wrong. The checker reports an opening without a code recorded before the choice as "not verified", so those voters get no false assurance.
