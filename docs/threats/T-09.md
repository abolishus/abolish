# T-09: Plaintext vote reaches a server, log, analytics or chain

- Area: Ballot secrecy, unlinkability and privacy (G-3, G-4, G-5, G-12)
- Adversary: A-2, A-1
- Status: **Planned.**

## Threat

Plaintext vote reaches a server, log, analytics or chain.

## Mitigation

Encryption happens only in `apps/ballot`, through `packages/crypto` APIs; servers only ever see ciphertexts and proofs. `apps/ballot` ships no third-party runtime code and no analytics, under a strict CSP, with a bundle test (P2-8). Review rule 2 in `claude-review`.
