# T-51: Data loss

- Area: Availability and censorship resistance (G-10)
- Adversary: A-7, A-2
- Status: **Needs decision** (P1-6). IPFS alone is addressing, not storage. Residual if adopted: Arweave's permanence is an economic assumption, the newest periods have only IPFS copies until they are confirmed on Arweave, every archived ciphertext is permanent (T-15), and display text survives only while someone pins it, so a result can stay verifiable but not interpretable (T-53).

## Threat

Board data unpinned from IPFS disappears, so a result can no longer be recomputed.

## Mitigation

Board data, election definitions and our contracts' L2 events are archived on Arweave once per anchoring period, and pinned on IPFS by us, commercial services and community nodes ([[0005-permanent-archive]], P1-6, P4-3, P4-5); display text is committed by salted hash and kept off the archive (T-17). Integrity comes from L1 anchors, so any copy can be checked.
