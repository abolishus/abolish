# P2-2: `packages/api-contract`

- State: in review
- Branch: `claude/p2-2`
- Phase: Phase 2: Open polls end to end at Tier 0

## Scope

`packages/api-contract` (oRPC, `zod/mini`) + OpenAPI generation.

## Built

- **Contract** (`src/contract.ts`): `elections.getDefinition`, `board.getHead`, `board.getEntries`, `board.getInclusionProof`, `board.getConsistencyProof` and `ballots.submit`, each with an explicit REST route and typed errors. P2-3 implements them.
- **Wire forms** (`src/wire.ts`): lowercase hex with one spelling per byte string, 32-byte hashes, canonical decimal `u64` strings and page sizes, and the bounds `MAX_BOARD_PAYLOAD` (tied to [[parameters]] by a test), `MAX_BOARD_ENTRY`, `MAX_PAGE` (256), `MAX_PAGE_BYTES` (8 MiB) and `MAX_PROOF_PATH` (128). Protocol bytes stay opaque: `@abolishus/crypto` decodes them (T-31).
- **OpenAPI**: `build` writes `dist/openapi.json` from the contract, deterministically, so `repro-build` compares it. Publishing it with each release is the release item's (P2-11).
- **Threats:** T-09 and T-10 (no field names an account, session, person or plaintext vote, and no operation declares authentication: both tested), T-31 (one encoding per byte string, no protocol schema), T-52 (every input and output bounded), T-23, T-24 and T-34 (every answer carries canonical bytes the caller checks itself).

## Tested

`vp run --filter @abolishus/api-contract test`: fast-check properties of every wire form (acceptance of all valid values, rejection of uppercase hex, odd lengths, prefixes, non-canonical decimals and out-of-range values); every object the generated document defines is strict; an extra request field is refused; the banned-name and no-authentication checks; the operation list; deterministic generation; the `MAX_BOARD_PAYLOAD` tie to the spec; `zod/mini` as the only Zod import.

## Known-weak

- **Not yet in the contract:** spoiled-ballot openings (P1-13), trustee intake (P1-14, which runs on the trustees' own endpoints), anchored checkpoints (P4-1) and registration (P3). Each item adds its procedures here.
- **The ballot client and this package's runtime dependencies.** `@orpc/contract` and `zod` are runtime dependencies. `apps/ballot` (P2-8) should import the contract's types only, or call the API through `@abolishus/sdk`, so no third-party runtime code reaches the ballot bundle unless P2-8 decides otherwise.
- **Hex doubles the size of every byte string on the wire.** It matches the spec's notation and vectors; a binary transport can come later without changing the contract's meaning.
- **Bounds are schemas, not limits.** Request-body size limits, rate limits and Turnstile belong to P2-3 and P2-5; the schema only refuses an oversize value once it is parsed.
