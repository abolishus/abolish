# T-59: A PR weakens the gate that judges it

- Area: Development, supply chain and operations (G-14)
- Adversary: A-8, A-2
- Status: **Partial.** Depends on the owner enabling code-owner review on `main`, which agents can't verify ([[STATUS]], Known-weak).

## Threat

A PR weakens the gate that judges it.

## Mitigation

Gate code lives under `.github/` (CODEOWNERS); review prompts and verdict scripts are read from the base commit; the brief is pinned verbatim by CI.

Index: [[THREAT_MODEL]].

## History

- 2026-10-10 (P0-ops): rule B prefers package-local checks over new `.github/tools/ci` code. To keep this mitigation, that preference covers only tests of a package's own behaviour; checks that enforce a policy (dependencies, imports, encodings, bundles, the gated-package rules) stay under `.github/`. A package-local test outside CODEOWNERS can be weakened in the same PR it judges, so it is never the only gate on a policy.
