# T-30: Weak Fiat–Shamir binding ("Frozen Heart")

- Area: Integrity and verifiability (G-7, G-8, G-9)
- Adversary: A-9, A-2
- Status: **Planned.**

## Threat

A challenge that omits part of the statement lets a prover forge proofs or transplant them across elections.

## Mitigation

Challenges hash the entire statement: domain tag, election ID, public key, every commitment and ciphertext, poll ID, chain ID and contract address (`crypto-review` skill; P1-8, P1-12). The challenge is a uniform scalar from RFC 9497's `HashToScalar` construction with the tag as its `DST` ([[0007-group-and-hash]]), never a reduced 32-byte digest.
- 2026-10-13 (P3-4 part 2b-3a, [[keyed-nullifier-hashes]]): the first In-circuit tags, `abolish/v1/keyed-nullifier/h1` and `/h2`, each with a fixed input count (3 and 5) in a Poseidon2 sponge whose capacity element carries the count; `circuitTagField` now returns their field elements and still refuses every other primitive's tag.

Index: [[THREAT_MODEL]].

## History

- 2026-10-10 (P1-11): challenges derived with RFC 9497's `HashToScalar` construction, the tag as `DST` ([[0007-group-and-hash]]), instead of reducing a 32-byte digest.
- 2026-10-10 (P1-11, implementation): `challenge(tag, t)` in `packages/crypto` takes only specified Fiat–Shamir tags (none yet: P1-12 specifies the first statement layouts); `HashToScalar` checked against RFC 9497 Appendix A.1 under its own DSTs and against `hash.json` under ours.
- 2026-10-11 (P1-17c): a tag enters a circuit only as `tag_field(tag)`, derived from the registered string under `abolish/v1/circuit-tag`, and only for a tag registered In-circuit ([[domain-separation]], In-circuit hashes), so a circuit and an off-circuit hash can't use different tags and no plain-hash tag gets a second layout.
- 2026-10-11 (P1-12, part 1): the first statement layouts. Each validity challenge binds `statement_hash` (definition hash, ballot record type and version, tier, nullifier, every VSS commitment and every share-ciphertext hash, hashed once under `abolish/v1/ballot-statement`), the proof's position (option index, or `min` and `max` for the sum), the commitment and every prover commitment ([[ballot-validity]]). [[domain-separation]] now allows a statement digest in place of the statement under these conditions. Vectors show a proof failing under another election, tier, nullifier, share-ciphertext hash, option position or range.
