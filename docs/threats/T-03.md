# T-03: Forged, stolen or duplicated documents at Tier 2

- Area: Eligibility and Sybil resistance (G-1, G-2)
- Adversary: A-1, A-9
- Status: **Partial by design.** Possession of a document isn't personhood: a person with two valid documents, or a stolen document with its access data, gets two identities. A state that issues documents (A-1) can mint identities for its own citizens. Stated in the P3-1 ADR.

## Threat

One person registers with several documents (a passport and an mDL, or two passports), or with someone else's document.

## Mitigation

Tier 2 proves validity of an issuer-signed document and derives a per-document uniqueness nullifier (P3-1 ADR, P3-4).

## History

- 2026-10-11 (P1-17): membership is proven against a complete depth-32 tier tree, so one registration (one document's uniqueness nullifier) carries at most one voting identity; over Semaphore's LeanIMT it could have carried a private tree of them ([[membership]], Tier tree).
- 2026-10-11 (P3-1): [[0010-tier2-identity-provider]] chooses zkPassport's scoped per-document nullifier. zkPassport checks passive authentication only, so cloned chip data proves; its documentation states "one ID, one account", not one person. The verifier ties the proof's date to the addition's L2 time and requires an unexpired document, so a backdated proof can't register an expired document; a renewed or replaced document whose old chip still reads still gives a second identity. The nullifier type is fixed per deployment and a removal never frees a nullifier. So anyone holding a document's chip data (including the issuing state and a malicious proof-app build) can pre-register it and permanently burn its holder's nullifier; the holder's only recourse is a new document until P3-2 and P3-4 design a dispute path.
- 2026-10-12 (P1-17b): the tier tree is implemented and checked against an independent implementation, including forbidden commitments (leaf 0) and stray removals.
- 2026-10-12 (P3-4 part 1, [[0022-tier2-keyed-nullifier]]): the Tier 2 nullifier becomes `H2(x, sk · H1(x))` under the panel's threshold OPRF key, with `x` zkPassport's per-document private nullifier, so one document still yields one nullifier; each attester recombines the evaluation from the seats' proven answers and checks the output proof against it, and an addition counts only with `max(k, n − 1)` attesters signing its group position after every earlier nullifier reached them, so a duplicate needs 5 corrupt seats of 7. Open for part 2: if an accepted document signer uses ECDSA and zkPassport's circuit doesn't fix the SOD signature's encoding and low `s`, a holder gets a second per-document input and so a second nullifier. Losing the key ends the scope and means re-registration.
- 2026-10-12 (P3-4 part 2a, [[0022-tier2-keyed-nullifier]], Amendment): the document signature's encoding is canonical. zkPassport takes ECDSA signatures as fixed-width `r ‖ s` with low `s` and range-checked `r` and `s`, and RSA signatures below the modulus, so a holder can't re-encode one signature into a second per-document input `x`. Our query circuit must also reject `x = 0`, which zkPassport's hash-only commitment form admits. Uniqueness still rests on the soundness of zkPassport's identity sub-circuits, on which a question is held for the owner (details withheld until the owner decides on disclosure). Until it is settled, real documents don't register through them.
- 2026-10-12 (P3-4 part 2b-2a, [[nullifier-key]]): an honest seat approves at most one Tier 2 key per scope, and a key counts only with `max(k, n − 1)` seats' approvals, so a second key for one scope, and with it a second nullifier for every document, needs a seat that broke that rule.
- 2026-10-13 (P3-4 part 2b-2b, [[nullifier-reshare]]): a reshare keeps the Tier 2 key's `sk`, since each dealer's constant commitment must be its share commitment `C_i` (`constant`), so every nullifier stays the same across a panel change; a new seat approves at most one successor of any key, and a successor counts only with `max(k', n' − 1)` new seats' approvals, so a key has at most one counted successor and a scope's keys form one chain.
- 2026-10-13 (P3-4 part 2b-2b review, [[nullifier-reshare]]): an old seat deals to at most one successor panel per predecessor while a run to it is live, and a successor counts only with `max(k, n − 1)` dealers, a rule of counting itself, not only of honest approvers (a panel of an insider's own keys has none), so two successor panels need an old seat that dealt to both; for 4-of-7 the two dealer quorums share 5 seats, at least one honest. Smaller panels rely on the release pinning one successor.
- 2026-10-13 (P3-4 part 2b-3a, [[keyed-nullifier-hashes]]): `H1` and `H2` are deterministic in the scope and `x`, so one document has one `N` provided the circuits enforce three things the page states: the map's root sign rule (canonical `sgn0`, whose soundness in Noir 1.0.0-beta.22 was checked), the unblinded `U` in Baby Jubjub's prime-order subgroup (TACEO's audit finding A; otherwise an even `r` admits `U + T` and a second `N`), and `x ≠ 0` in the query circuit.
