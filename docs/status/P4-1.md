# P4-1: Hourly L1 anchoring

- State: in progress (part 1: the L1 board anchor contract, in review)
- Phase: Phase 4: Censorship resistance

## Scope

Hourly L1 anchoring of board roots (worker + contract).

## Plan

1. **The board anchor** (this part): the L1 contract and its spec, [[contracts]], Board anchor. The anchoring clock's values (hourly periods, a 12-hour deadline), the anchoring authority, the window and one-checkpoint-per-segment rules, and how a verifier reads every anchor of an election from state.
2. **The hourly job and the deployment:** a worker job (P2-4, #64) that computes each election's checkpoint after every period and sends them through the Safe, from two independent runners, with alerts well before the deadline; a deploy script and a `ci:` workflow deploying the anchor to Sepolia with source verification, and the deployment record. Needs #64 merged and a `ci:` PR (rule B).
3. **Reading anchors:** the verifier's L1 inputs (P1-19 part 3) and the receipt check (P1-13) read the per-segment slots with storage proofs.

## What was built (part 1)

- `packages/contracts`:
  - `BoardAnchor` (`src/BoardAnchor.sol`): immutable `epoch`, `period`, `deadline` and `authority`; `anchor(bytes)` takes concatenated checkpoint encodings from the authority only, refuses an empty board, a checkpoint outside `[end, end + deadline]` of its period, and a second checkpoint for an election and segment (equal or not, across calls or within one); stores the checkpoint hash at an ERC-7201 slot per election and segment; emits `CheckpointAnchored` with the full checkpoint through the event accumulator. Deployment refuses a zero period and an authority without code.
  - `CheckpointLib`: the checkpoint hash, `H(DS("abolish/v1/board-checkpoint", encode(checkpoint)))`.
  - `CanonicalCalldata` (`src/CanonicalCalldata.sol`): the election registry's canonical-calldata check, moved to a library both contracts use. The registry's revert data is unchanged.
- [[contracts]], Board anchor: deployment values and why the deadline is 12 hours, the anchoring rules, the event, and verification from state; [[board]], Owned elsewhere, points there.
- Threats: T-23, T-24, T-52, T-53, T-49, T-50, T-17, T-69.

## Tested (part 1)

- Every checkpoint in `docs/spec/vectors/board.json` (from the independent Python generator) hashes to its published hash in Solidity, and the `valid` board's anchors, each sent at its vector time under the vectors' clock, are all accepted and stored under those hashes.
- A unit test per refusal (caller, empty board, before the period ends, past the deadline, before the epoch, a second checkpoint equal or not, twice in one call, malformed lengths, non-canonical calldata: a trailing word or byte, dirty padding, a moved argument), the window's exact boundaries on both sides, all-or-nothing calls, several elections in one call, the log's topics and data and the accumulator, and the hash at the documented storage slot.
- No personal data: the calldata and log of a real anchor pass the registry's text detector, and text appended to a checkpoint is refused.
- Fuzz: any checkpoint at any time is stored exactly when it is non-empty and inside its window, under its hash.
- Invariant suite (time moves, three elections, eight segments, batches of up to three, calls from strangers): the stored hashes equal a shadow of the first in-window checkpoint per election and segment, calls succeed exactly when the rules allow, and the accumulator counts every anchored checkpoint. Passes under `FOUNDRY_PROFILE=ci`.
- Mutation checks by hand: loosening the deadline by one second, opening the window one second early, dropping the empty-board, duplicate, authority, canonical-calldata or code check, or changing the tag's length byte each fail a test.

## Known-weak

- Nothing is deployed and nothing anchors yet (part 2), so every board is unanchored and the `reference-election` check can't cover anchoring until P1-20 uses this contract on Anvil.
- The anchoring authority can still fail a running election, attributably, by anchoring a checkpoint no board matches first; the contract then keeps it. A Safe makes that a quorum's act, not one key's ([[contracts]], Board anchor, Known-weak).
- The anchor can't refuse a segment past an election's seal (it can't read the definition); verifiers ignore those.
- One checkpoint costs about 82,000 gas, each further one in a call about 32,000.
