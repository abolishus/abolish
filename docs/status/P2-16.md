## Scope

[[0027-trustee-panels-and-live-results]], Parts 1 and 3:

- **Author-added trustees.** A ballot's opening is split additively in two; the default half is shared to the default panel and the author half to the author's panel, each with its own threshold, so a ballot opens only with both thresholds and the author panel can never lower secrecy below the default panel's. The definition binds the author panel's keys, threshold and ceremony transcript; the verifier checks them off chain. If fewer than `k_A` author seats take part at the close, the poll can never be counted, and the UI says so plainly.
- **The transitional panel.** At launch the default panel is ours alone (4-of-7, seats spread so no machine, provider or keyholder holds 4). Every page and receipt says "During launch, Abolish alone holds the key for this poll"; only everyday polls run under it, checked through a panel kind in the release pins and the trustee registry and a poll class in the definition; shares are destroyed after each final count; seats hand over to named independent trustees before the first civic-record poll.

## What was built (part 3b, #292)

- [[tally]], Author panel: tally-opening **version 3**, which a poll with an author panel pins (version 2 is [[P2-15]]'s). Each panel's aggregates over the one counted set (delivery version 2 over both panels), its seats' summed shares checked against its own aggregates and sent only to its own seats, its partial opening by its own `k_P` seats, and the cell's count as the sum of the two partial openings, which opens `Ĉ_{c,j}` because `C_j = E^D_{j,0} · E^A_{j,0}`. Why a partial opening reveals nothing beyond the count, and binding per panel.
- **Summed-share message version 2** (`0x000b`): version 1 with `panel` after `cell`, the panel in the AEAD's associated data and the recipient's key from its panel's registered key set; same tags, since both inputs start with the record type and version.
- **Tally opening version 3** (`0x0006`): version 1 with `panel` after `cell`, signed under a new tag, `abolish/v1/sig/partial-opening`, over the whole record but its signature, header included, so a version-3 signature can't be re-read as a shifted version-1 message; attributed only to a seat of the panel it names. Sorting (a panel byte other than 1 or 2 is stray), the per-cell checks (`tally-missing` and `tally-opening` per panel, `tally-conflict` per panel, `tally-range` and `tally-question-range` on the summed count), and the boarding rule per cell, panel and seat.
- **The author panel publishes first** (`crypto-review` on #292): honest default seats send any partial opening only once a passing author partial opening of every cell is boarded under a checkpoint they checked, and the operator boards a default one only after all of them (election-wide, so the author can't read one cell's count and withhold another) (`tally-early` otherwise), so the author panel commits before it can know the count and can't make its refusal depend on the result; one default seat leaking its partial opening early defeats it (residual).
- **The author panel's deadline and whose failure** (`crypto-review` on #292): `AUTHOR_OPENING_WINDOW` (4 days after `t_S`) bounds the author's partial opening; the checks look at the author panel first, and a default opening missing after a late author one is `tally-author-late`, the author panel's or the operator's, so the report never blames the default panel for an author's refusal.
- **Author or operator** (`crypto-review` on #292): a cell failure that follows from the author's partial opening is attributed to "the author panel or the board operator" until P1-18's contract path for tally openings lets author timeliness be judged by L2 submission time; the results page never says the author's trustees failed without that evidence.
- **Separate sums, per-panel 8.2** (`crypto-review` on #292): the claim that both partial openings reveal what one opening does is limited to an adversary that reads no posted half; a residual states the per-panel anonymity set against a future adversary (with an operator-steered attack at `k_A = 1`), [[verifier]] 8.2 counts readable ballots per panel, and ADR 0027's posting-fallback sentence is amended. Masking each panel's opening is left to part 3c.
- **Destruction statement version 2** (`0x000f`): version 1 with `panel`, signed over its header; every seat of both panels destroys once every cell has a passing opening for each panel (or at `t_D`), and the destruction checks run per seat of each panel. The windows are version 1's values.
- [[verifier]] 2.3: a version-6 definition with an author panel must pin tally-opening version 3 and board-entry version 7, one without must not pin version 3; 2.3 still refuses author panels until the author transcript's chosen-byte channel is closed or accepted. 7.2 to 7.4, 8.4 and 8.5 per panel.
