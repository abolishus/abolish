# T-58: Prompt injection against the autonomous pipeline

- Area: Development, supply chain and operations (G-14)
- Adversary: A-8
- Status: **Partial.** Model behaviour is probabilistic; an injection that convinces both the author agent and the reviewers lands unless it touches a CODEOWNERS path.

## Threat

Text in issues, PRs, comments, dependencies or the web redirects an agent or a review model.

## Mitigation

Agents and both reviews treat that content as data (AGENTS.md, Hard rules); the review model runs with no shell on a prepared read-only view, with instruction files renamed, and the verdict is judged in a separate job using the base commit's prompt; attempts are recorded in STATUS without quoting.
