# T-39: Cryptographic implementation flaws

- Area: Integrity and verifiability (G-7, G-8, G-9)
- Adversary: A-9, A-2, A-6
- Status: **Planned.** Residual: JavaScript gives no hard constant-time guarantees; `@noble/*` documents its own limits, which apply to us.

## Threat

Reused or biased encryption randomness (reused ElGamal randomness leaks vote differences), non-CSPRNG randomness, missing point or subgroup validation (invalid-curve and small-subgroup attacks), secret-dependent timing, or a hand-rolled or non-audited primitive creeping in.

## Mitigation

Primitives only from audited `@noble/*` (`packages/crypto` depends on nothing else, CI-checked, closure check in P1-9); point and scalar codecs with subgroup and canonicity checks (P1-11); secret randomness only from the platform CSPRNG, owned by `packages/crypto`, with deterministic randomness only behind a test seam; constant-time secret comparison; published vectors and property tests; `crypto-review` (P1-9, P1-11, P1-12).
