## Scope

From [[0009-membership-proof]] and [[membership]]:

- Vendor Semaphore v4's depth-32 Groth16 verification key (the only depth Abolish uses, [[membership]], Tree depth) from `semaphore-protocol/semaphore` at the tag and commit [[membership]] cites, with source, commit and sha256 re-fetched in CI. Allowing that publisher needs a `ci:` PR first (rule B).
- Specify `abolish/v1/membership-vk`: the hash of the pinned key set that the election definition's `membership_vk_hash` carries (P1-10b), and the proof encoding a ballot carries.
- Check the pinned depth-32 proving key's reference string for well-formedness once, publicly (Fuchsbauer, PKC 2018), and bind the checked key into `abolish/v1/membership-vk`: without it, zero knowledge against a subverted ceremony isn't established ([[membership]], Security notes).
- Groth16 verification over BN254 in the gated packages, on `@noble/curves`' BN254 pairing: the published verification equation, no new primitive ([[0009-membership-proof]], Consequences). Strict decoding of proof points (canonical coordinates, on the curve, in the prime-order subgroup, G2 included); every public input below `r`; the key's `IC` exactly 5 points; only pinned keys.
- The tier tree ([[membership]], Tier tree): rebuild a tier's root from its additions, as verifier 2.4 needs. It needs circomlib's `Poseidon2` over BN254, from `@noble/curves`' Poseidon with circomlib's published parameters vendored and checked against circomlib's own test vectors.
- Real Semaphore proofs as vectors (generated with Semaphore's own tooling outside the gated packages, recorded with their source), plus tampered proofs, wrong public signals, a proof under another depth's key, wrong scope (including another tier's scope over the same root) a proof against root 0 (proof length above the depth), a hidden-subtree proof (a registered value that is the root of a private tree, proven with a path longer than its leaf's), and removals by commitment, all rejected; and a tier tree with a forbidden addition (`0`, `1`, `Poseidon2(0, 1)`, non-canonical) whose leaf is 0 and whose definition passes, and a tier whose only additions are forbidden (root `Z_32`), whose definition fails; and removals of an out-of-range or already-removed index, which change nothing. The real proofs' scope and message inputs, made by Semaphore's own `hash`, also tie `F` in `membership.json` to Semaphore's output, which P1-17 checked only against Keccak known answers.

## Notes

- Groth16 proofs are malleable; replay detection never compares proof bytes ([[verifier]] 5.7, 6.1 R1).
