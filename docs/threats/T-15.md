# T-15: Harvest now, decrypt later

- Area: Ballot secrecy, unlinkability and privacy (G-3, G-4, G-5, G-12)
- Adversary: A-11
- Status: **Partial by design.** The public board itself is perfectly hiding, provided the tally publishes only each cell's opening ([[0015-tally-publication]]); published per-trustee summed shares would let a later break of posted shares' encryption complete ballots with fewer than `k` posted shares. Residual: share ciphertexts harvested in transit are only post-quantum conjectured (Module-LWE), or classical if ML-KEM can't be used unaudited; shares posted publicly (offline or refusing trustees, direct submit) have only classical (Shor-breakable) privacy, and each trustee offline during voting lowers the harvest threshold for the ballots it missed.

## Threat

ElGamal ciphertexts on the public board are only computationally hiding; a future quantum computer or discrete-log break reveals every historic vote.

## Mitigation

[[0002-everlasting-privacy]] (P1-3, accepted: option B): perfectly hiding Pedersen and VSS commitments on the board, with each trustee's shares sent off the board under a hybrid ML-KEM + Diffie–Hellman KEM, so nothing the protocol normally publishes reveals a vote to any future adversary. The tally publishes only each cell's opening, never a trustee's summed shares, which would fix the summed polynomials at every seat and, with posted shares, complete ballots for a future adversary ([[0015-tally-publication]], [[tally]]). Remaining: a corrupt trustee, which sees the summed shares, has that power ([[tally]], Residuals).

Index: [[THREAT_MODEL]].

## History

- 2026-10-10 (P1-11): `h = hash_to_ristretto255("", DST = "abolish/v1/generator-h")`, published with its intermediate bytes in `docs/spec/vectors/hash.json` so anyone can check no one chose it ([[group]]).
- 2026-10-11 (P1-12, part 1): the public part is specified ([[ballot-validity]]): each VSS commitment has a uniform, independent `h` exponent, so it is perfectly hiding, and honest validity proofs simulate their false branches, so they are witness-indistinguishable against an unbounded adversary; both are within about 2⁻²⁵⁰ of ideal, from reducing 64 CSPRNG bytes per scalar. `packages/crypto` proves only a sharing it made itself, so no caller can choose a commitment's randomness. Share encryption (the computational part) is part 2.
- 2026-10-11 (P1-15, part 1): `crypto-review` on #55 found that publishing each trustee's summed shares, as ADR 0002 had it, fixes the summed polynomials at every seat, so a future adversary (A-11) who breaks the classical encryption of posted shares can complete a ballot with fewer than `k` posted shares (with a relay, A-2, shaping the postings, or by accident). [[0015-tally-publication]] (option C) publishes only each cell's opening; summed shares go only between trustees under the hybrid KEM. Residual: a corrupt trustee sees the summed shares and has the same power ([[tally]], Residuals).
- 2026-10-11 (P1-15, part 1): verifier 8.2 reports, per cell, the counted ballots with passing postings at fewer than `k` distinct seats: a future adversary reads every other ballot, and the opening gives the sum of these ([[tally]], Residuals).
