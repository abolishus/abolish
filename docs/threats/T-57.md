# T-57: Malicious insider change

- Area: Development, supply chain and operations (G-14)
- Adversary: A-2, A-8
- Status: **Partial.** Non-CODEOWNERS changes merge on CI plus model review alone (see [[STATUS]], Known-weak). The owner can change anything. Since rule A (2026-10-10), one-way-door ADRs (privacy model, cryptographic protocol, canonical encoding, chain, permanent storage) are decided by the agent and merge on CI plus model review, with only an owner veto after the fact; owner-only decisions (trustees, mainnet, funds, legal, the brief's non-negotiable properties) still wait for the owner.

## Threat

A maintainer, an agent or we land code that weakens secrecy or integrity.

## Mitigation

All code is public; required checks (`ci`, `claude-review`, `crypto-review`); CODEOWNERS owner review for `.github/` and agent-instruction and build-config paths; reproducible builds (P0-3) so the deployed code is the reviewed code; the verifier lets anyone catch a wrong result regardless.

Index: [[THREAT_MODEL]].

## History

- 2026-10-10 (P0-ops): **weakened by rule A.** One-way-door ADRs no longer wait up to 72 hours for the owner; they merge on CI plus model review and are listed under Decisions to review in [[STATUS]] for an after-the-fact veto. Residual: an agent-made protocol or privacy choice can be built on before the owner reads it; a veto then means rework, not prevention.
