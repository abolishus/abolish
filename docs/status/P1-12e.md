# P1-12e: Complaints carried many to a signature

- State: done (on `claude/ecstatic-noether-nx7ory` with [[P1-12d]], at the owner's request; the national-scale obligation is [[P1-12f]])
- Phase: Phase 1: Threat model, spec, crypto core, circuits, verifier, reference election (CLI only)

## Scope

With receipts batched ([[P1-12d]]), complaints at about 157,000 gas each bound the forced path's cap at about 23,600 members with 3 seats ([[delivery]], Capacity; T-25, T-52, T-54). Built inside contract-event version 4, before anything pins it, so no further contract-event version is needed.

## What was built

- [[delivery]], Share-complaint batch: record type `0x0017`, version 1 (fixed by ballot versions 1 to 3): `definition_hash`, `seat`, `complaints` (1 to `COMPLAINT_BATCH_MAX` = 512 entries of `ballot_hash` and `complaint_proof`, strictly ascending by ballot hash) and one `p256-sig` under `abolish/v1/sig/share-complaint-batch`. Each entry reads as the complaint it states, attributed by the batch's signature; contract path only. Capacity: `COMPLAINTS_PER_CALL` 512 and `COMPLAINT_CALL_GAS` 5,000,000 (measured cold: about 4,566,000), `G_K = s · ⌈2M / COMPLAINTS_PER_CALL⌉ · COMPLAINT_CALL_GAS`. Caps: 20,992 members with 3 seats at `R` of one hour (receipts bind), 434,688 at 21 hours (complaints bind).
- [[contracts]]: `submitComplaintBatch(bytes)` and `ShareComplaintBatchSubmitted(bytes32 indexed definitionHash, uint8 indexed seat, bytes record)`, in contract-event version 4's table; the event check frames each `D` as the board does, never decoding it (T-53).
- `packages/crypto` (`SHARE_COMPLAINT_BATCH`, its codec and statement, `batchShareComplaints`, `frameComplaintBatch`, the delivery check, `FORCED_PATH`), `packages/contracts`, `packages/verifier` (5.9 reads the event; `pair` in excluded complaints) and `packages/sdk`'s counting.
- Vectors from independent Python: `delivery-batch.json` gains complaint batches, `contract-event-v4.json` the event (with a batch whose `D` frames but isn't a point, which passes), `delivery-obligation.json` the figures, `verifier-events.json` the records.

## Tested

As P1-12d's, for complaint batches: every vector re-made, every decode rejection at its offset in TypeScript, Solidity and Python, every election's verdicts, the event under versions 3 and 4, the board accepting every vector batch with its event and refusing stray, seat, signature and tag, and the gas figure bound to measured gas, cold.
