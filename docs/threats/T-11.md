# T-11: Network-level linkage

- Area: Ballot secrecy, unlinkability and privacy (G-3, G-4, G-5, G-12)
- Adversary: A-2, A-1, A-10
- Status: **Not mitigated.** Anyone seeing network traffic (us, Cloudflare, an ISP, A-1) can correlate an IP across registration and voting. Voters who need protection must use Tor or another anonymity network; the client must not break under it. Under P1-3 (option B), each trustee's intake also sees submission metadata, so up to n more parties can correlate IPs.

## Threat

Our servers, CDN or an RPC provider see the same IP or browser fingerprint at registration and at ballot submission, or time-correlate them.

## Mitigation

Ballot submission uses no account session and no cookies; the API's own request log drops IPs on the ballot path (P2-3); the proxy's and the platform's logs are residuals (History, P2-11). Direct submit (T-25) bypasses us entirely. Under [[0002-everlasting-privacy]] (P1-3, option B): a direct submit still delivers its shares to the n trustees' intakes, or posts them publicly, so it bypasses us but not the trustees.

## History

- 2026-10-11 (P1-13): a client's check of its ballot's L1 block after finality must not be a targeted request for that one block, which would link its network address to the ballot ([[revoting]], Client rule 4).
- 2026-10-11 (P2-11 part 1): [[railway]] turns off Cloudflare's log exports (no Logpush, no Log Explorer), but Cloudflare still keeps WAF and rate-limit matches as security events with the client address and query string, so a rate-limit match on ballot submission records an address with its time. Railway's own HTTP logs can't be turned off and may record client addresses. Both are more parties that see addresses, never with an account session on the ballot path (T-10).
- 2026-10-11 (P2-10 part 2): a poll report keeps no address and no time of its own (only the hour its ground's oldest unreviewed report arrived). An insider reading the counters repeatedly, or holding the write-ahead log or backups, can still time a report, and Railway's HTTP logs may hold the address with that time. A rate-limit match on `POST /moderation/reports` is a Cloudflare security event like any other, with the reporter's address.
