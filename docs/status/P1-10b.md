## Scope

Split from [[P1-10]], which built the primitive codecs, record framing and `DS` framing. This item specifies and implements version 1 of the election definition (`0x0001`) and the display-text record (`0x0009`) in `docs/spec/` and `packages/crypto`, with vectors (`docs/spec/vectors/election-definition.json`, `display-text.json`) and the `profile-mismatch` vectors. It also specifies the `abolish/v1/election-definition` tag's input layout.

Waits on: the group and hash layer (P1-11) for `H` and for group elements in the definition; the trustee panel encoding ([[0006-trustees]], which the owner decides) for the panel field, which until then can be a test panel.

## Carried over from P1-10's reviews

Non-blocking findings from the #21 reviews, which this item should close:

- **The definition's own version pin.** The election definition carries the profile, so it can't be decoded against a pin known in advance. Add a dedicated definition decoder: decode `UNPINNED`, then reject with `profile-mismatch` unless the decoded version equals the profile's pin for `0x0001`. Add a vector for it. Otherwise, once a second definition version exists, a creator could encode a new election under a retired layout (T-34, T-31; [[verifier]] check 2.3). Also correct the `packages/crypto` README, which says only vector files and tests pass `UNPINNED`.
- **Error code precedence.** When a record's version is both unknown to the decoder and not the pinned one, `RecordSchema.decode` reports `unknown-version`, while [[verifier]] 2.3 says `profile-mismatch`. Settle which code wins in [[notation]] and the vectors, then make the code match.
- **Unregistered record numbers.** A production `RecordSchema` (without `allowTestRange`) accepts any number from 1 to `0xfeff`, including numbers the registry never assigned. Reject numbers outside `RECORD_TYPES` unless the test range is allowed, so [[versioning]] stays the only place numbers are assigned.
- **`struct()` keeps the caller's fields array.** Copy and freeze the fields when the codec is made, so the layout can't change after a record type registers it.
