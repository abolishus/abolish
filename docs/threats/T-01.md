# T-01: Sybil accounts at Tier 0

- Area: Eligibility and Sybil resistance (G-1, G-2)
- Adversary: A-1, A-9
- Status: **Not mitigated** (by design: Tier 0 is open polling). Tier 0 results must be labelled as not Sybil-resistant everywhere they appear.

## Threat

Passkeys are free; anyone can register many Tier 0 identities.

## Mitigation

Results are always reported per tier, so Tier 0 is never presented as one-person-one-vote. The verifier enforces the labels: each ballot is tallied in the cell of the tier it proved, and each tier's root comes from that tier's own group additions (verifier 2.4, 2.8). Turnstile and rate limits raise the cost (P2-5).
